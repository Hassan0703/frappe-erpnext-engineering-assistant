# Brand assets

Logo files for the Frappe ERPNext Engineering Assistant. Both are PNG with an alpha channel.

| File | Format | Size | Use it for |
|---|---|---|---|
| [`primary-logo-horizontal-lockup.png`](primary-logo-horizontal-lockup.png) | Horizontal lockup, light background | 637 × 152 | Document headers: the root [`README.md`](../README.md) title block, presentations, release announcements |
| [`stand-alone-logo-square-format.png`](stand-alone-logo-square-format.png) | Standalone mark, transparent | 135 × 139 | Square/app-icon contexts: the plugin icon (`plugins/frappe-erpnext-engineering-assistant/.claude-plugin/icon.png`), the [plugin README](../plugins/frappe-erpnext-engineering-assistant/README.md) header, avatars |

Rules of use:

- Keep the lockup intact — do not re-typeset the name or split the mark from the text.
- Do not recolor, stretch, or crop the mark; scale proportionally only.
- Do not add a background, shadow, or outline to the standalone mark.
- The plugin icon is a copy of the standalone mark; when the mark changes, copy it over
  (`cp images/stand-alone-logo-square-format.png plugins/frappe-erpnext-engineering-assistant/.claude-plugin/icon.png`).
